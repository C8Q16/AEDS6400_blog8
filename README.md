# Blog Post 8: From Clicks to Confidence

A reproducible Python tutorial on bootstrap confidence intervals, confidence interval coverage, and simulation-based hypothesis testing.

## Purpose

This project uses a fictional online store to make statistical inference easier to understand. It demonstrates how to construct a bootstrap interval, evaluate its coverage across repeated samples, and interpret rejection regions and p-values under a null hypothesis.

All observations are simulated. No external dataset, account, API key, or data download is required. The true conversion rate is deliberately known so that interval coverage can be measured.

## 3. Generate the initial sample and bootstrap interval

### Population model

Each visitor independently purchases with probability 0.10. The notebook simulates 500 visitors using:

```python
sample = rng.binomial(1, true_p, size=n)
```

A purchase is coded as 1 and a non-purchase as 0. The mean is the sample conversion rate.

### Bootstrap procedure

1. Retain the initial sample of 500 visitors.
2. Draw 500 observations from that sample with replacement.
3. Calculate the resample's mean.
4. Repeat 2,000 times.
5. Take the 2.5th and 97.5th percentiles of the bootstrap means.

These percentiles form a percentile bootstrap 95% confidence interval.

Resampling uses the observed sample, not the known population probability. Sampling with replacement allows an observation to appear more than once in a resample.

### Output

`figure1.png` displays the bootstrap distribution, the initial sample estimate, and the confidence interval endpoints.

The reported run produced 45 purchases, a sample conversion rate of 9%, and a confidence interval of [6.6%, 11.6%].

## 4. Evaluate confidence interval coverage

The next section repeats the complete sampling-and-estimation process:

1. Generate a new independent sample of 500 visitors from the population with purchase probability 0.10.
2. Construct an interval using 1,000 bootstrap resamples of that sample.
3. Check whether the interval contains the known true rate, including its endpoints.
4. Repeat for 1,000 independent samples.
5. Divide the number of successful intervals by 1,000.

There are two distinct levels of repetition:

- **Within each sample:** bootstrap resampling estimates uncertainty.
- **Across samples:** repeated population sampling evaluates the interval procedure's coverage.

The reported run produced 952 intervals containing the true rate, giving coverage of 95.2%.

### Output

`figure2.png` displays only the first 100 intervals for readability. Blue intervals contain 10%; red intervals miss it. The title reports coverage across all 1,000 samples.

Coverage near 95% illustrates long-run performance in this simulation setting. It does not guarantee 95% coverage for every population or sample size, and it does not assign a probability to a fixed parameter after an individual interval has been calculated.

## 5. Simulate hypothesis testing

This section introduces a separate hypothetical observation: 60 purchases among 500 visitors, giving a conversion rate of 12%. It is not the initial sample with 45 purchases.

The hypotheses are:

- Null: the population conversion rate is 10%.
- One-sided alternative: the population conversion rate exceeds 10%.

The test statistic is the number of purchases.

### Construct the null distribution

Generate 50,000 purchase counts using:

```python
null_counts = rng.binomial(n, null_p, size=S)
```

This directly simulates the total number of purchases among 500 independent visitors under the null.

### Estimate the rejection region

For each possible count, calculate the simulated probability of that count or a larger one. Select the smallest count whose upper-tail probability is no greater than 0.05.

The reported rejection region is 62 or more purchases. Because counts are discrete, the actual rejection probability need not equal exactly 5%. The threshold is estimated from simulation.

### Estimate the p-value

Count simulations with at least 60 purchases. The code uses a small Monte Carlo adjustment:

```python
p_value = (
    np.sum(null_counts >= observed_purchases) + 1
) / (S + 1)
```

The reported p-value is 0.0807. It exceeds 0.05, so the null is not rejected at the 5% level.

This means the example provides insufficient evidence that the true rate exceeds 10%. It does not prove that the rate equals 10%, and the p-value is not the probability that the null hypothesis is true.

### Output

`figure3.png` contains two panels:

- Red bars: the simulated rejection region.
- Orange bars: outcomes at least as large as the observed statistic, used to estimate the one-sided p-value.

## Assumptions and limitations

- Visitors are independent and share the same purchase probability.
- This is a teaching simulation, not an analysis of an actual store.
- Percentile bootstrap intervals have approximate coverage, especially with small samples or probabilities near zero or one.
- Coverage estimates, p-values, and rejection thresholds have simulation error.
- The interval example and testing example use different observations and should not be presented as the same sample.
- The notebook assumes a single conversion probability and does not model repeat visitors, seasonality, or differences between customers.
